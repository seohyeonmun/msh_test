# FinePrint
### 구독형 서비스 약관 기반 소비자 보호 AI Agent

## 1. 프로젝트 소개

FinePrint는 구독 서비스의 해지·환불·자동결제 문제에 대해  
서비스 약관과 소비자 보호 자료를 함께 검색하고, 답변을 검증해  
사용자가 확인해야 할 사항과 다음 행동을 안내하는 AI Agent입니다.

- **개발 기간**: 2026.07.01 ~ 2026.07.23

---

## 2. 기획 배경

- 구독 서비스 이용 과정에서 해지·환불·자동결제 관련 문제가 반복적으로 발생
- 문제가 발생한 뒤 사용자가 관련 약관과 소비자 보호 기준을 직접 찾기 어려움
- 같은 문제라도 결제 시점, 해지 완료 여부, 서비스 이용 여부에 따라 확인해야 할 조건이 달라짐
- 일반 생성형 AI의 답변은 실제 약관과 일치하는지 확인하기 어려움

> **FinePrint는 사용자의 문제 상황을 약관 및 소비자 보호 근거와 연결하고,  
> 확인사항과 다음 행동을 제공하기 위해 기획했습니다.**
