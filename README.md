# FinePrint
### 구독형 서비스 약관 기반 소비자 보호 AI Agent

## 1. 프로젝트 소개

FinePrint는 구독 서비스의 해지·환불·자동결제 문제에 대해  
서비스 약관과 소비자 보호 자료를 함께 검색하고, 답변을 검증해  
사용자가 확인해야 할 사항과 다음 행동을 안내하는 AI Agent입니다.

> **개발 기간**: 2026.07.01 ~ 2026.07.23

---
## 2. 기획 배경

- 구독 서비스 이용 과정에서 해지·환불·자동결제 관련 문제가 반복적으로 발생
- 해지 수수료와 취소 조건이 약관과 절차 속에 포함되어 있어 사용자가 직접 확인하기 어려움
- 같은 문제라도 결제 시점, 해지 완료 여부, 서비스 이용 여부에 따라 확인해야 할 조건이 달라짐
- 일반 생성형 AI의 답변은 실제 약관과 일치하는지 확인하기 어려움

> **FinePrint는 사용자의 문제 상황을 서비스 약관 및 소비자 보호 근거와 연결하고,  
> 확인사항과 다음 행동을 안내하기 위해 기획했습니다.**

## 3. 주요 기능

#### 1) 약관 수집 및 문서 업로드
- 공식 약관 URL을 탐색하고 웹페이지 본문을 수집
- 자동 수집이 어려운 경우 URL 또는 PDF·TXT 파일 입력 지원
- 약관과 법령의 구조를 반영해 조항·섹션 단위로 분할

#### 2) Hybrid RAG 기반 근거 검색
- 서비스 이용약관과 소비자 보호 자료를 함께 검색
- 의미 기반 검색과 도메인 키워드 재정렬을 결합
- 서비스명과 문서 유형 메타데이터를 활용해 관련 없는 문서 제외

#### 3) 근거 검증 AI Agent
- 사용자 질문을 해지·환불·자동결제·결제·개인정보 등의 유형으로 분류
- 생성된 답변과 검색 근거의 일치 여부를 별도로 검증
- 실패 원인에 따라 답변 재생성 또는 근거 재검색 수행
- 반복 검증 후에도 근거가 부족하면 무리하게 단정하지 않고 근거 부족 안내 제공

#### 4) 실행 가능한 답변 제공
- 문제 상황에 대한 조건부 결론 제공
- 해지일·결제일·서비스 이용 여부 등 확인사항 안내
- 고객센터 문의 방법과 준비 자료 제시
- 실제 사용한 조항, 원문과 출처 링크 제공

## 4. 사용자 흐름

사용자는 서비스와 약관 확보 방식을 선택한 뒤 문제 상황을 입력합니다.  
FinePrint는 검색·생성·검증을 수행하고, 최종적으로 근거와 다음 행동을 제공합니다.

## 6. Agent 동작 흐름

사용자 질문의 지원 범위를 분류한 뒤 근거를 검색하고 답변을 생성합니다.  
검증 결과에 따라 최종 답변, 답변 재생성, 근거 재검색 또는 근거 부족 안내 경로로 분기합니다.

## 7. 답변 검증 및 재시도 구조

FinePrint는 검색된 문서를 바탕으로 답변을 생성한 뒤,  
별도의 검증 단계에서 답변이 실제 근거와 일치하는지 확인합니다.

검증에 실패한 경우 모든 답변을 같은 방식으로 다시 처리하지 않고,  
실패 원인에 따라 재시도 경로를 구분했습니다.

| 분기 경로 | 판단 기준 | 처리 방식 |
|---|---|---|
| `PASS` | 답변이 검색된 근거와 일치함 | 최종 답변 생성 |
| `REGENERATE` | 근거는 충분하지만 답변 표현이 부정확하거나 과도하게 단정적임 | 기존 근거를 유지하고 답변만 재생성 |
| `RETRIEVE_AGAIN` | 사용자의 상황을 판단하기 위한 근거가 부족함 | 검색 전략을 보완해 관련 문서를 다시 검색 |
| `INSUFFICIENT` | 최대 재시도 후(2회)에도 필요한 근거를 확보하지 못함 | 가능 여부를 단정하지 않고 근거 부족 안내 제공 |

### 재시도 제한

- 검증 실패 시 `retry_count`를 증가시킵니다.
- 최대 재시도 횟수를 설정해 무한 반복을 방지했습니다.
- 재시도 이후에도 근거가 부족한 경우, 확인사항과 추가로 필요한 자료를 안내합니다.

> 답변 생성 실패와 검색 실패를 구분해 필요한 단계만 다시 수행함으로써,  
> 불필요한 반복을 줄이고 근거와 답변의 일치도를 높였습니다.
