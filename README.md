# FinePrint - 구독형 서비스 약관 기반 소비자 보호 AI Agent
### 1. 프로젝트 소개
- 구독형 서비스 대상으로 문제 상황에 있는 소비자들의 권리를 보호하기 위한 Agent 입니다.
- 구독 약관과 소비자 보호 기준을 함께 검색하고, 답변을 검증해 실행 가능한 다음 행동까지 제시하는 AI Agent 입니다.
- 개발기간
  > 2026.07.01 ~ 2026.07.23
---
### 2. 기획 배경
- 구독형 서비스 이용 과정에서 자동결제·환불·해지 문제가 반복적으로 발생함
  > https://themiilk.com/articles/ab8fff01a
- 문제 발생 시 필요한 약관과 정책 내용을 찾기 어려움  
- 문제 유형에 따라 적절한 해결 경로와 준비사항이 다름
    
**=> FinePrint를 통해 사용자 상황 맞춤형 문제 해결 안내를 제공하고자 함**
